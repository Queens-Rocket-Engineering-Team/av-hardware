# Shared Libraries

Shared KiCad libraries for components used across multiple avionics boards.

## Structure

- `footprints/` - Shared PCB footprints.
- `models/` - Shared 3D models.
- `symbols/` - Shared schematic symbols.


Only components intended for use across multiple boards should be placed here. Board-specific assets should remain within the respective board directory.
